03 / install one tool

A complete standalone demo.

Python 3.11+ and Git 2.38+. No companion Jonah-UX repository, API key, database, or service needed.

python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install 'git+https://github.com/jonah-ux/worktree-conservator.git@v0.2.0'
worktree-conservator --version
worktree-conservator demo --json

The installed CLI includes the demo. It constructs its own temporary repositories and runs the workflow there. No existing worktree is selected.

04 / first real step

Look before you touch.

After inspecting the demo, start with the read-only inventory for a repository you select explicitly.

worktree-conservator scan \
  --repo /absolute/path/to/your-repo \
  --root /absolute/path/to/your-worktrees \
  --base-ref origin/main --json

Replace example paths before use. Refresh the remote base separately. A refusal remains a refusal; nothing here grants approval to retire a worktree.

What is proved by the real tool: a reviewed plan, pinned identity, archive bytes, and explicit removal/recovery postconditions when the corresponding CLI checks succeed. What this page proves: only the documented decision flow. Archives preserve committed content; they are not backups of uncommitted work or a substitute for the repository's Git objects.
